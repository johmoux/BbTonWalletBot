# BB Wallet 🏦 | The Best Ton Wallet  

**BB Wallet** is a secure, fast, and easy-to-use cryptocurrency wallet built for **TON (The Open Network)**. It allows users to send, receive, and store **Toncoin (TON)** with a seamless experience.  

## 🚀 Features  

✅ **Secure & Private** – Your data stays on your device.  
✅ **Fast Transactions** – Send and receive TON instantly.  
✅ **Onboarding Experience** – Step-by-step setup with a secure backup phrase.  
✅ **Transaction History** – Track past transactions easily.  
✅ **QR Code Support** – Receive payments by sharing your QR code.  
✅ **Telegram Web App Integration** – Works inside Telegram.  
✅ **Beautiful UI** – Built with **TailwindCSS** and **Phosphor Icons**.

- **Frontend:** HTML, CSS (TailwindCSS), JavaScript  
- **UI Library:** Phosphor Icons  
- **Swiper.js** (for onboarding slides)  
- **Telegram Web App SDK**  

## 📦 Installation  

BB Wallet is built for **[Bots.Business](https://bots.business)** and is designed to run inside Telegram bots.  

1. **Deploy the wallet on Bots.Business**  
2. **Configure your Telegram bot**  
3. **Use it seamlessly within Telegram**  

## ⚙️ Configuration  

If you're integrating with a backend or blockchain API, update the configuration in:  
```sh
/assets/js/bbwallet.app.main.js
```

## 💡 How to Use  

1. Open the wallet in Telegram.  
2. Secure your **seed phrase**.  
3. Send & receive **Toncoin (TON)** securely.  
4. Track transactions in **history**.
